Web & HTML Temelleri

İnternetin nasıl çalıştığını, HTTP protokolünü, URL yapısını ve HTML'in temellerini öğren. 21 konu, 10 quiz sorusu.

📖 21 Konu 📝 10 Quiz Sorusu ⏱ ~3-4 saat

▸01 İnternet Nasıl Çalışır?

İnternet, milyarlarca cihazı birbirine bağlayan küresel bir ağ altyapısıdır. Web (World Wide Web) ise bu altyapı üzerinde çalışan bir hizmettir — interneti bir otoyol sistemi, web'i bu otoyoldaki bir servis olarak düşünebilirsiniz.

📡 İnternet vs Web

İnternet = Fiziksel ağ altyapısı (kablolar, sunucular, yönlendiriciler). Web = Bu altyapı üzerindeki bir uygulama katmanı.

Bir web sayfasını açtığınızda arka planda şunlar olur:

  1. DNS Çözümlemesi — Alan adı, IP adresine çevrilir.
  2. TCP Bağlantısı — Tarayıcı ile sunucu arasında güvenli kanal kurulur.
  3. HTTP İsteği — Tarayıcı sayfayı ister.
  4. HTTP Yanıtı — Sunucu HTML, CSS, JS gönderir.
  5. Render — Tarayıcı içeriği görüntüler.
🛡️ Güvenlik Notu

DNS zehirlenmesi (DNS poisoning) saldırısında saldırgan, alan adını kötü niyetli bir IP'ye yönlendirebilir. Bu yüzden HTTPS ve HSTS kritik önem taşır.

▸02 HTTP Protokolü

HTTP (HyperText Transfer Protocol), istemci ve sunucu arasındaki iletişimi yöneten kurallar bütünüdür. HTTPS, bu protokolün TLS/SSL ile şifrelenmiş versiyonudur.

HTTP Metodları

HTTP Metodları
GET    /sayfa.html        → Veri al (güvenli, idempotent)
POST   /api/login         → Veri gönder (form, JSON)
PUT    /api/user/1        → Kaynağı güncelle (tam)
PATCH  /api/user/1        → Kısmen güncelle
DELETE /api/user/1        → Kaynağı sil

HTTP Durum Kodları

Önemli Durum Kodları
200 OK              → Başarılı
201 Created         → Oluşturuldu
301 Moved           → Kalıcı yönlendirme
302 Found           → Geçici yönlendirme
400 Bad Request     → Geçersiz istek
401 Unauthorized    → Kimlik doğrulanmamış
403 Forbidden       → Erişim reddedildi
404 Not Found       → Bulunamadı
500 Server Error    → Sunucu hatası
✅ Yap: Hassas veriler için daima HTTPS kullan
❌ Yapma: HTTP üzerinden şifre veya token gönderme

▸03 URL Anatomisi

URL (Uniform Resource Locator), bir kaynağın internet üzerindeki tam adresidir.

URL Bileşenleri
https://www.example.com:443/sayfa?q=html&lang=tr#bolum1
│       │                │  │     │               │
│       │                │  │     │               └─ Fragment (hash)
│       │                │  │     └─ Query string (sorgu parametreleri)
│       │                │  └─ Path (yol)
│       │                └─ Port (443 HTTPS varsayılan)
│       └─ Domain (alan adı)
└─ Şema (protocol)
⚠️ Dikkat: URL'de parola, kredi kartı veya token gönderme! URL'ler server loglarına kaydedilir ve başkalarına görünür olabilir.

▸04 Tarayıcı Nasıl Çalışır?

Tarayıcı bir HTML belgesini alıp ekranda görüntülemek için birkaç adımdan geçer:

  1. HTML Parse — HTML okunarak DOM ağacı oluşturulur.
  2. CSS Parse — CSS okunarak CSSOM ağacı oluşturulur.
  3. Render Tree — DOM + CSSOM birleştirilir.
  4. Layout — Her elementin boyutu ve konumu hesaplanır.
  5. Paint — Ekrana çizilir.
💡 Neden Önemli? Performans optimizasyonu için tarayıcının ne zaman "reflow" ve "repaint" yaptığını bilmek kritiktir.

▸05 HTML Nedir?

HTML (HyperText Markup Language), web sayfalarının yapısını tanımlayan bir işaretleme dilidir. Programlama dili değildir — içeriğin anlamını ve yapısını tanımlar.

📌 HTML'in 3 Rolü
  • Yapı — Sayfanın iskeletini oluşturur (HTML)
  • Görünüm — Nasıl görüneceğini belirler (CSS)
  • Davranış — Nasıl davranacağını belirler (JavaScript)

▸06 İlk HTML Dosyası

Her HTML belgesi belirli bir yapıya sahip olmalıdır. İşte minimal ama geçerli bir HTML belgesi:

index.html — Minimal HTML Şablonu
<!DOCTYPE html>
<html lang="tr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sayfa Başlığı</title>
</head>
<body>
  <h1>Merhaba Dünya!</h1>
  <p>Bu benim ilk HTML sayfam.</p>
</body>
</html>

<!DOCTYPE html> — Tarayıcıya bu belgenin HTML5 olduğunu söyler. lang="tr" — Dil bilgisi SEO ve erişilebilirlik için zorunludur.

▸08 <head> Bölümü

<head> görünür içerik barındırmaz; sayfayla ilgili meta bilgileri tutar.

head Bölümü Örneği
<head>
  <meta charset="UTF-8">                     <!-- Karakter kodlaması -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Sayfa açıklaması">
  <title>Başlık — Site Adı</title>
  <link rel="stylesheet" href="style.css">   <!-- CSS bağlantısı -->
  <link rel="icon" href="favicon.ico">        <!-- Favicon -->
</head>

▸09 <body> Bölümü

Kullanıcının gördüğü tüm içerik <body> içinde yer alır.

body Yapısı

  </header>

  <main>

  </main>

</body>

▸10 Başlık Etiketleri (h1-h6)

HTML'de 6 seviye başlık etiketi vardır. Hiyerarşik kullanım SEO ve erişilebilirlik için kritiktir.

Başlık Hiyerarşisi
<h1>Ana Başlık — Sayfada sadece BİR tane</h1>
<h2>Bölüm Başlığı</h2>
<h3>Alt Bölüm</h3>
<h4>Alt-alt Bölüm</h4>
<h5>Nadir kullanılır</h5>
<h6>En nadir kullanılır</h6>
✅ Yap: h1'den h2'ye, h2'den h3'e sıralı ilerle
❌ Yapma: Görünüm için h etiketleri seçme (bunun için CSS kullan)

▸12 Bağlantılar — <a>

Bağlantı Örnekleri
<!-- Dış bağlantı -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Dış Site
</a>

<!-- İç bağlantı -->
<a href="/hakkimizda.html">Hakkımızda</a>

<!-- Sayfa içi -->
<a href="#bolum1">Bölüm 1'e git</a>

<!-- Email -->
<a href="mailto:info@example.com">E-posta gönder</a>

<!-- Telefon -->
<a href="tel:+905551234567">Ara</a>
🛡️ Güvenlik: rel="noopener noreferrer"

target="_blank" kullanırken her zaman rel="noopener noreferrer" ekle. Aksi halde açılan sayfa window.opener ile ana sayfana erişebilir (Reverse Tabnabbing saldırısı).

▸16 Formlar

Temel Form Yapısı
<form action="/submit" method="POST">
  <label for="email">E-posta:</label>
  <input type="email" id="email" name="email" required>

  <label for="password">Şifre:</label>
  <input type="password" id="password" name="password" required minlength="8">

🛡️ Güvenlik: Form method="POST"

Hassas veri içeren formlar için her zaman method="POST" kullanın. GET metodu verileri URL'e ekler ve loglanır.

▸17 Semantik HTML

Semantik HTML, etiketlerin içeriğin anlamını da taşımasıdır. Bu SEO, erişilebilirlik ve bakım kolaylığı sağlar.

Semantik vs Non-semantik
<!-- ❌ Anlamsız -->
<div class="header"><div class="nav">...</div></div>
<div class="main"><div class="article">...</div></div>
<div class="footer">...</div>

<!-- ✅ Anlamlı -->
<header><nav>...</nav></header>
<main><article>...</article></main>
<footer>...</footer>

▸19 HTML Karakter Varlıkları

Sık Kullanılan Varlıklar
&lt;     →  <   (küçüktür)
&gt;     →  >   (büyüktür)
&amp;    →  &   (ampersand)
&quot;   →  "   (çift tırnak)
&apos;   →  '   (tek tırnak)
&nbsp;   →     (bölünemez boşluk)
&copy;   →  ©   (telif hakkı)
&mdash;  →  —   (em dash)
&euro;   →  €   (euro)
💡 İpucu: HTML içinde < ve > karakterlerini kullanırken mutlaka varlık kodlarını kullanın. Aksi halde tarayıcı bunları etiket olarak yorumlar.

▸20 HTML Doğrulama

🔧 Araçlar:

📝 Bölüm 1 Quizi

10 soru · %70 geçme eşiği · Tüm soruları cevapla

1. HTTP ve HTTPS arasındaki temel fark nedir?
a) HTTPS daha hızlıdır
b) HTTPS verileri TLS ile şifreler
c) HTTP yalnızca resimler için kullanılır
d) HTTPS yalnızca mobil için çalışır
✓ Doğru Cevap: B — HTTPS, HTTP'nin TLS/SSL katmanıyla şifrelenmiş versiyonudur. Veriler transit sırasında okunmaktan korunur.
2. <!DOCTYPE html> ne işe yarar?
a) HTML4 belirtir
b) Dil ayarını belirler
c) Tarayıcıya HTML5 kullanıldığını söyler
d) Sayfa başlığını tanımlar
✓ Doğru Cevap: C — DOCTYPE bildirimi tarayıcıya standart modu aktifleştirmesini söyler ve HTML5 belgesi olduğunu belirtir.
3. target="_blank" kullanırken hangi rel değeri zorunludur?
a) rel="noopener noreferrer"
b) rel="external"
c) rel="blank"
d) Hiçbiri gerekmez
✓ Doğru Cevap: A — rel="noopener noreferrer" olmadan açılan sayfa window.opener ile ana sayfaya erişebilir (Reverse Tabnabbing).
4. Hangi HTTP durum kodu "Kaynak bulunamadı" anlamına gelir?
a) 200
b) 403
c) 500
d) 404
✓ Doğru Cevap: D — 404 Not Found, istenen kaynağın sunucuda bulunamadığını belirtir.
5. Bir sayfada kaç tane <h1> etiketi olmalıdır?
a) Sınır yok
b) Yalnızca bir tane (SEO ve a11y için)
c) En az iki tane
d) h1 kullanılmamalıdır
✓ Doğru Cevap: B — SEO ve ekran okuyucular için bir sayfada yalnızca bir h1 olmalıdır.
6. <strong> ve <b> arasındaki fark nedir?
a) Fark yoktur, ikisi de aynıdır
b) <b> HTML5'te kaldırılmıştır
c) <strong> anlamsal önem taşır, <b> sadece görsel
d) <strong> sadece CSS ile çalışır
✓ Doğru Cevap: C — <strong> "önemli" anlamı taşır (ekran okuyucular vurgular), <b> sadece görsel kalın efekti verir.
7. Hassas veri içeren form için doğru method hangisidir?
a) method="POST"
b) method="GET"
c) method="PUT"
d) method="SEND"
✓ Doğru Cevap: A — POST verileri request body'de taşır. GET ise URL'e ekler ve loglanır.
8. <img> etiketinde alt özelliğinin önemi nedir?
a) Görselin boyutunu belirler
b) Erişilebilirlik ve SEO için açıklamalı metin sağlar
c) Görselin alternatif URL'sidir
d) Yalnızca dekorasyon içindir
✓ Doğru Cevap: B — alt metni, görüntüleyemeyen kullanıcılar (görme engelliler, yavaş bağlantı) için açıklama sağlar.
9. HTML yorumlarına neden gizli bilgi yazılmamalıdır?
a) Yorumlar veritabanına kaydedilir
b) Yorumlar HTTPS ile şifrelenmez
c) Yorumlar tarayıcıda çalışır
d) Yorumlar kaynak kodda herkese görünür
✓ Doğru Cevap: D — HTML yorumlar kaynak kodda görünür. "Kaynağı görüntüle" ile herhangi bir kullanıcı okuyabilir.
10. Semantik HTML kullanmanın en önemli avantajı hangisidir?
a) SEO, erişilebilirlik ve kod okunabilirliği
b) Sayfa daha hızlı yüklenir
c) CSS daha az kod gerektirir
d) JavaScript otomatik çalışır
✓ Doğru Cevap: A — Semantik HTML, arama motorlarına, ekran okuyuculara ve diğer geliştiricilere içeriğin anlamını iletir.
