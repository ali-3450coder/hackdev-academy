HTML'deki Tüm Etiketler

Metadata'dan medyaya, formlardan ARIA'ya HTML spesifikasyonunun tam kapsamlı incelemesi. 26 konu, 12 quiz sorusu.

📖 26 Konu📝 12 Quiz Sorusu⏱ ~4-5 saat

▸01 Metadata Etiketleri — <head> içinde ne olur?

Head bölümündeki meta etiketler, sayfanın tarayıcılar, arama motorları ve sosyal medya platformları tarafından nasıl işleneceğini belirler.

Head Metadata Tam Örneği
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Sayfa açıklaması (150-160 karakter)">
  <meta name="keywords" content="html, web, geliştirme">
  <meta name="author" content="Ad Soyad">
  <meta name="robots" content="index, follow">

  <title>Sayfa Başlığı — Site Adı</title>

  <link rel="canonical" href="https://example.com/sayfa">
  <link rel="stylesheet" href="style.css">
  <link rel="icon" type="image/x-icon" href="/favicon.ico">
  <link rel="preconnect" href="https://fonts.googleapis.com">

  <base href="https://example.com/"> <!-- Tüm linklerin base URL'si -->

  <style>/* Kritik CSS buraya */</style>
  <script src="analytics.js" async></script>
</head>

▸02 Semantik Yapı Etiketleri

Semantik Yapı Elemanları
<header>  → Sayfa veya bölüm başlığı, logo, nav içerir
<nav>     → Navigasyon linkleri
<main>    → Sayfanın ana içeriği (bir tane olmalı)
<section> → Tematik içerik grubu (başlığı olmalı)
<article> → Bağımsız, dağıtılabilir içerik (blog yazısı)
<aside>   → Ana içerikle ilgili ama ayrı (sidebar)
<footer>  → Sayfa veya bölüm alt bilgisi

<!-- Kullanım örneği -->
<body>
  <header>
    <nav><ul><li><a href="/">Ana Sayfa</a></li></ul></nav>
  </header>
  <main>
    <article>
      <h1>Makale Başlığı</h1>
      <section><h2>Bölüm</h2><p>...</p></section>
    </article>
    <aside><p>İlgili Linkler</p></aside>
  </main>
  <footer><p>© 2025</p></footer>
</body>

▸03 Başlık Hiyerarşisi — SEO ve Erişilebilirlik

Başlık hiyerarşisi hem SEO hem de screen reader kullanıcıları için sayfa yapısını tanımlar.

Doğru Başlık Hiyerarşisi
<!-- ✅ Doğru: Hiyerarşik -->
<h1>Site/Sayfa Ana Başlığı</h1>
  <h2>Bölüm 1</h2>
    <h3>Alt Bölüm 1.1</h3>
    <h3>Alt Bölüm 1.2</h3>
  <h2>Bölüm 2</h2>
    <h3>Alt Bölüm 2.1</h3>

<!-- ❌ Yanlış: Seviye atlama -->
<h1>Başlık</h1>
<h3>Alt Başlık (h2 atlandı!)</h3>
💡 SEO Notu: Arama motorları h1-h6 hiyerarşisini kullanarak içerik önem sıralaması yapar. h1 en önemli anahtar kelimeyi içermeli.

▸06 Bağlantılar — <a> Etiketi Tam Rehber

Tüm a Özellikleri
<!-- href türleri -->
<a href="https://external.com" target="_blank" rel="noopener noreferrer">Dış Link</a>
<a href="/iletisim.html">İç Sayfa</a>
<a href="#bolum">Sayfa İçi</a>
<a href="mailto:info@site.com">E-posta</a>
<a href="tel:+905551234567">Telefon</a>
<a href="dosya.pdf" download="rapor.pdf">İndir</a>

<!-- rel değerleri -->
rel="noopener noreferrer"   → Güvenlik (target=_blank ile)
rel="nofollow"              → Arama motoruna takip etme
rel="canonical"             → Tercih edilen URL
rel="alternate"             → Alternatif dil/format
rel="author"                → Yazar sayfası
rel="license"               → Lisans bilgisi
🛡️ Güvenlik: Phishing Koruması

Kötü niyetli siteler window.opener.location ile ana sayfanızı değiştirebilir. Çözüm: rel="noopener noreferrer"

▸09 Responsive Görseller — picture, srcset

<!-- srcset + sizes ile genişlik bazlı -->
<img
  src="foto-800.jpg"
  srcset="foto-400.jpg 400w, foto-800.jpg 800w, foto-1200.jpg 1200w"
  sizes="(max-width: 600px) 400px, (max-width: 1000px) 800px, 1200px"
  alt="Responsive Fotoğraf"
>

<!-- picture: format ve art direction -->
<picture>
  <source srcset="foto.avif" type="image/avif">
  <source srcset="foto.webp" type="image/webp">
  <source media="(max-width: 768px)" srcset="foto-mobil.jpg">
  <img src="foto.jpg" alt="Fotoğraf"> <!-- Fallback -->
</picture>

▸14 Form Validasyonu — HTML5 Özellikleri

Native Form Doğrulama
<input
  type="email"
  required                           → Boş bırakılamaz
  minlength="5"                      → Min karakter
  maxlength="100"                    → Max karakter
  min="18"                           → Sayısal minimum
  max="99"                           → Sayısal maksimum
  pattern="[a-z0-9._%+\-]+@[a-z0-9.\-]+\.[a-z]{2,}$"  → Regex
  title="Geçerli e-posta girin"      → Hata mesajı hint
  placeholder="ornek@mail.com"       → Yer tutucu
  autocomplete="email"               → Tarayıcı otofill
  inputmode="email"                  → Mobil klavye tipi
>
✅ Yap: HTML5 validasyonu + JavaScript + sunucu tarafı üçlü doğrulama
❌ Yapma: Yalnızca client-side validasyona güvenme. Kolayca atlanır!

▸16 Gömme Etiketleri — iframe, embed, object

iframe Güvenli Kullanımı
<!-- ✅ Güvenli iframe -->
<iframe
  src="https://www.youtube.com/embed/VIDEO_ID"
  width="560"
  height="315"
  title="Video Açıklaması"
  loading="lazy"
  sandbox="allow-scripts allow-same-origin allow-presentation"
  allow="fullscreen"
  referrerpolicy="no-referrer"
></iframe>

<!-- sandbox değerleri: -->
allow-scripts          → JavaScript çalışabilir
allow-same-origin      → Same-origin politikası
allow-forms            → Form submit
allow-popups           → Pop-up açabilir
allow-downloads        → İndirme
🛡️ Güvenlik: Clickjacking

Kendi sayfanızın iframe içine gömülmesini engellemek için CSP'de frame-ancestors 'none' veya X-Frame-Options: DENY kullanın. sandbox olmayan iframe'ler çeşitli saldırılara kapı açar.

▸19 Script ve Stil Yönetimi

Script Yükleme Stratejileri
<!-- Normal: HTML parse durdurur, bekler -->
<script src="script.js"></script>

<!-- defer: HTML parse bitmeden indirir, sonra çalışır -->
<script src="script.js" defer></script>

<!-- async: paralel indirir, hazır olunca çalışır (sıra garantisi yok) -->
<script src="analytics.js" async></script>

<!-- type="module": ES6 modülü, otomatik defer -->
<script type="module" src="app.js"></script>

<!-- Inline script -->
<script>console.log('Çalışıyor');</script>

<!-- Stil -->
<link rel="stylesheet" href="style.css" media="print">
<style media="screen">body { margin: 0; }</style>
💡 Performans İpucu: JavaScript dosyalarını </body> öncesine veya defer ile head'e koy. Bu sayede tarayıcı HTML'i önce parse eder.

▸24 Güvenlik Açıklı Etiketler

🛡️ XSS: Cross-Site Scripting

Kullanıcı girdisini doğrudan HTML'e ekleme! Her zaman encode et veya DOMPurify kullan.

Güvenlik Açıkları ve Çözümleri
<!-- ❌ XSS açığı -->
<p id="msg"></p>
<script>
  const userInput = location.search; // ?name=<script>alert(1)</script>
  document.getElementById('msg').innerHTML = userInput; // TEHLİKELİ!
</script>

<!-- ✅ Güvenli -->
<script>
  document.getElementById('msg').textContent = userInput; // textContent kullan
</script>

<!-- ❌ Tehlikeli iframe (sandbox yok) -->
<iframe src="https://guvenilmez.com"></iframe>

<!-- ✅ Sandbox ile iframe -->
<iframe src="https://guvenilmez.com"
  sandbox="allow-scripts"
  referrerpolicy="no-referrer"></iframe>

<!-- CSP header ile script injection engelle -->
<meta http-equiv="Content-Security-Policy"
  content="default-src 'self'; script-src 'self'">
